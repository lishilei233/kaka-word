# 咔咔单词视频工作室

TanStack Start + React + Tailwind CSS 4 + shadcn/ui 源码组件 + Remotion 的本地视频制作工具。

网页、素材接口、系统配音、草稿与视频导出均由 **TanStack Start 的 server routes** 提供。无需 `npm run worker`，也不再使用 3211 端口。

## 启动

```bash
cd video-studio
npm install
npm run dev
```

打开 http://127.0.0.1:3210。需要 Node.js 22.12+，以及 Mac 系统英语音色、PATH 中的 `ffmpeg` / `ffprobe`。Remotion 优先使用本机 Chrome；未安装时可能下载渲染浏览器。

## 接入原 server 的识别接口

请求链路为浏览器 → TanStack Start `/studio-api/analyze` → 原 `server` 的 `/v1/analyze`。Start 只转发照片、词数和连接凭证，解析 SSE 的完整结果及照片描述。模型、AI 密钥和费用控制由原 `server` 管理，网页项目不读取或配置 Qwen / Gemini / 火山密钥，也不直接实例化 provider。

默认连接 http://127.0.0.1:8787。若使用远端服务，在 `.env` 设置 `SERVER_API_URL`。原服务需按其原有方式运行；不用另开工作室专属后端。

`server` 支持仅供视频工作室使用的固定服务凭证。在 `server/.env` 设置 `VIDEO_STUDIO_ACCESS_TOKEN`，并把同一个值写入 `video-studio/.env` 的 `SERVER_ACCESS_TOKEN`。该凭证只在 `/v1/analyze` 生效，跳过 App 用户订阅额度和 DeviceCheck，但仍遵守服务端每分钟与每日调用上限。凭证只由 TanStack Start 服务端读取，不会进入浏览器，也不是重复配置 AI 密钥。

## 制作流程

1. 上传图片或视频（最大 100 MB）。视频播放到想要的画面后点击“使用这一帧”。取景段静音播放至该帧，后续照片固定。
2. 识别后校对单词、音标、中文，以及中英文照片描述；可调整标签位置和朗读顺序。标签使用与 App 相同的无重叠自动布局，引导线自动从胶囊最近边缘绕开其他标签。
3. 生成系统英语配音（默认 Samantha）。改英文会使该词的旧配音失效。
4. 预览并导出 1080×1920 / 30fps / H.264 MP4。逐词段只改变标签高亮，不放大或突出物体。
5. 打开工作室先进入“我的作品”，可新建、打开、命名、复制和删除多个独立视频。编辑停止 1 秒后自动保存，持续编辑时最多每 10 秒保存一次；顶部显示保存状态，失败可重试。返回作品首页前会完成待保存内容。

## 画面与平台留白

取景阶段与 App 的 `CameraView` 一致：预览层覆盖完整画布，素材按原始比例完整显示。发现单词阶段与 App 结果页一致：照片卡片左右各留 20pt，卡片内保留 8pt 相框边距，并使用照片原始宽高比；不会将横图或竖图裁成统一比例。

照片下方展示 AI 返回的中英文描述，可自行修改，中英文各最多两行。描述过长时建议缩短并检查预览。

默认顶部留白 180px、底部 360px、右侧 120px，可在编辑器调整。文字、当前单词、快门和标签会随留白重新布局。预览遮挡参考区不会进入成片。这是可调的保守模板，不是小红书或抖音的统一官方尺寸；平台的导航、按钮和文案长度可能改变遮挡范围，请结合发布预览检查。

旧草稿自动补充默认留白和空描述，原素材与配音路径继续兼容。

## 本地数据

素材、配音、草稿和成片位于 Git 忽略的 `.data/`。保留整个目录才能恢复素材。关闭网页服务会中止尚未完成的导出；重启后重新提交。

## 验证

```bash
npm run build
npm test
```

测试覆盖时间轴、改词配音失效、视频定格、满宽取景与安全区、旧草稿兼容、现有接口的 multipart / SSE 协议，以及认证、额度、限流和流中断错误。

### 照片描述与旧项目兼容

新生成或审校的描述包含 1–2 组 `captionSentences`，每组保存 `english`、`chinese`，配音后另有 `audio` 和 `audioSeconds`。英文每句目标 8–14 词，上限 18 词；`caption`、`captionChinese` 由这些句子拼接，继续用于发布文案。

项目格式升级为 v4，支持读取 v1–v3。没有分句数据的旧描述及原配音保持一整段，不按标点自动拆分。修改分句后需要重新审校和配音；更换音色或语速会清除全部配音。预览及导出按各句音频实际时长依次展示对应中英文，互动提问接在最后一句之后。

## 场景问题式封面

“设计封面”默认使用照片铺满的 3:4 场景问题模板，输出 1080×1440 PNG。标题和最多三个精选英文词组成一个文字区，可放顶部或底部；拖动照片或使用取景滑块调整构图，缩放范围为 1–2 倍。180×240 缩略图用于检查信息流中的可读性。标题最多 40 字、两行，无法完整排下时会提示缩短并禁止导出。

封面与发布助手共用“场景名”（最多 29 字），默认读取 AI 识别的场景名，可手动修改。封面标题固定为“{场景}，你会几个单词？”，新模板与经典学习卡均生效，不再提供受众切换或 AI 标题候选。长标题无法排入两行时需缩短场景名后再导出。

精选词默认优先旧高亮词，再按词表顺序补足三个，也可全部隐藏；有未展示词时以黄色“+N 个词”提示。封面取景、标题和选词不改变视频及配音；随作品自动保存。项目格式仍为 v4，历史标题、候选和旧文案字段保留兼容，但不再决定显示内容。

## 固定发布文案

发布助手使用同一份只读文案，适用于小红书、抖音和视频号。标题固定为“看照片学单词｜{场景}”；正文包含固定开场、按朗读顺序用 ` / ` 连接的全部英文词、“再学一句”后的全部中英文句子，以及固定互动问题。四个话题为“生活英语、英语单词、看图学英语、英语学习”，复制时只附加一次。

修改场景名、词表或描述后立即同步，无需生成，不调用 AI。可分别复制标题、正文与话题或全文；场景名、词表或任一组中英文描述不完整时禁止复制并显示提示。复制为纯文本与真实换行，旧描述不会按标点重新拆句。`/studio-api/social-copy` 保持原三平台结构，返回同一份本地模板结果；原 server AI 接口继续保留兼容。

## 多作品与自动保存

首页 `/` 按最后修改时间展示作品；编辑地址为 `/projects/<id>`，可直接打开或刷新。新作品默认名为“未命名视频”，复制作品默认添加“副本”。作品各自保存素材、词表、配音、封面、发布文案，以及尚未选帧的视频来源，不包含作品内历史版本。

作品记录保存在 `.data/projects/<id>.json`（可由 `STUDIO_DATA_DIR` 指定数据目录），使用原子替换和保存修订号避免覆盖。原 `.data/project.json` 首次访问作品接口时自动导入，原文件保留作为备份；迁移标记避免重复导入，迁移失败会明确提示。旧单草稿写入接口返回升级提示。复制共享素材文件；删除只移除作品记录，不清理共享素材。请备份整个数据目录。

多标签页同时编辑会提示保存冲突：可重新加载服务器内容，或将当前修改另存为新作品。保存失败时内容仍留在当前页面，点击重试；有未保存内容时刷新或关闭页面会触发浏览器提示。关闭或强制退出前请等待“已保存”，本工具不提供离线或崩溃恢复。

导出状态按作品记录在服务进程内，返回作品后可继续查看；编辑内容变化后不再展示旧成片下载入口。服务重启会丢失任务状态，但已生成文件仍保留在 exports 目录。

接口：`GET/POST /studio-api/projects` 列出／创建作品；`GET/POST /studio-api/projects/<id>` 读取／保存；`POST .../<id>/copy` 复制；`POST .../<id>/delete` 删除；`GET .../<id>/export` 查询本次服务运行期间的导出状态。保存传入 `{ revision, content: { project, editor } }`，删除传入 `{ revision }`；过期修订号返回 409。

### 单词识别动画

物体词高亮时，四角识别框在 0.2 秒内从外围收拢对焦，再从物体处展开黄色胶囊；四角框保留至下一个词开始。选择物体词后，可在「识别框」中调整位置与宽高，或进入预览拖动框和四个角；支持恢复自动范围与预览动画。调整只保存识别范围，保留配音及朗读顺序。动作、状态词沿用原词卡动画。
