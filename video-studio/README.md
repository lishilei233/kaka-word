# 咔咔单词视频工作室

TanStack Start + React + Tailwind CSS 4 + shadcn/ui 源码组件 + Remotion 的本地视频制作工具。

网页、素材接口、系统配音、草稿与视频导出均由 **TanStack Start 的 server routes** 提供。无需 `npm run worker`，也不再使用 3211 端口。

## 启动

```bash
cd video-studio
npm install
npm run dev
```

打开 http://127.0.0.1:3210。需要 Node.js 22.12+，以及 Mac 系统英语音色、PATH 中的 `ffmpeg` / `ffprobe`。Remotion 优先使用本机 Chrome；未安装时可能下载渲染浏览器。

## 接入原 server 的识别接口

请求链路为浏览器 → TanStack Start `/studio-api/analyze` → 原 `server` 的 `/v1/analyze`。Start 只转发照片、词数和连接凭证，解析 SSE 的完整结果及照片描述。模型、AI 密钥和费用控制由原 `server` 管理，网页项目不读取或配置 Qwen / Gemini / 火山密钥，也不直接实例化 provider。

默认连接 http://127.0.0.1:8787。若使用远端服务，在 `.env` 设置 `SERVER_API_URL`。原服务需按其原有方式运行；不用另开工作室专属后端。

`server` 支持仅供视频工作室使用的固定服务凭证。在 `server/.env` 设置 `VIDEO_STUDIO_ACCESS_TOKEN`，并把同一个值写入 `video-studio/.env` 的 `SERVER_ACCESS_TOKEN`。该凭证只在 `/v1/analyze` 生效，跳过 App 用户订阅额度和 DeviceCheck，但仍遵守服务端每分钟与每日调用上限。凭证只由 TanStack Start 服务端读取，不会进入浏览器，也不是重复配置 AI 密钥。

## 制作流程

1. 上传图片或视频（最大 100 MB）。视频播放到想要的画面后点击“使用这一帧”。取景段静音播放至该帧，后续照片固定。
2. 识别后校对单词、音标、中文，以及中英文照片描述；可调整标签位置和朗读顺序。标签使用与 App 相同的无重叠自动布局，引导线自动从胶囊最近边缘绕开其他标签。
3. 生成系统英语配音（默认 Samantha）。改英文会使该词的旧配音失效。
4. 预览并导出 1080×1920 / 30fps / H.264 MP4。逐词段只改变标签高亮，不放大或突出物体。
5. “保存草稿”保存当前项目，刷新恢复；当前是一份手动保存的草稿。旧版草稿会自动迁移物体中心和标签位置。

## 画面与平台留白

取景阶段与 App 的 `CameraView` 一致：预览层覆盖完整画布，素材按原始比例完整显示。发现单词阶段与 App 结果页一致：照片卡片左右各留 20pt，卡片内保留 8pt 相框边距，并使用照片原始宽高比；不会将横图或竖图裁成统一比例。

照片下方展示 AI 返回的中英文描述，可自行修改，中英文各最多两行。描述过长时建议缩短并检查预览。

默认顶部留白 180px、底部 360px、右侧 120px，可在编辑器调整。文字、当前单词、快门和标签会随留白重新布局。预览遮挡参考区不会进入成片。这是可调的保守模板，不是小红书或抖音的统一官方尺寸；平台的导航、按钮和文案长度可能改变遮挡范围，请结合发布预览检查。

旧草稿自动补充默认留白和空描述，原素材与配音路径继续兼容。

## 本地数据

素材、配音、草稿和成片位于 Git 忽略的 `.data/`。保留整个目录才能恢复素材。关闭网页服务会中止尚未完成的导出；重启后重新提交。

## 验证

```bash
npm run build
npm test
```

测试覆盖时间轴、改词配音失效、视频定格、满宽取景与安全区、旧草稿兼容、现有接口的 multipart / SSE 协议，以及认证、额度、限流和流中断错误。

### 照片描述与旧项目兼容

新生成或审校的描述包含 1–2 组 `captionSentences`，每组保存 `english`、`chinese`，配音后另有 `audio` 和 `audioSeconds`。英文每句目标 8–14 词，上限 18 词；`caption`、`captionChinese` 由这些句子拼接，继续用于发布文案。

项目格式升级为 v4，支持读取 v1–v3。没有分句数据的旧描述及原配音保持一整段，不按标点自动拆分。修改分句后需要重新审校和配音；更换音色或语速会清除全部配音。预览及导出按各句音频实际时长依次展示对应中英文，互动提问接在最后一句之后。
