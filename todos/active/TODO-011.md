### TODO-011：优化设置页与会员购买页面 UI

- 类型：ui
- 优先级：P2
- 状态：待验证
- 需求描述：优化设置页和会员购买页面的 UI，提升两个页面的视觉呈现、信息层级与使用体验，并保持从设置页进入会员购买流程时的体验一致。
- 简要分析：
  - 用户事实：本次要求同时覆盖设置页和会员购买页面的 UI 优化。
  - 初步分析：两个页面共同承载会员状态查看、购买入口和购买操作，适合作为一个连续体验统一分析和验收，而不是拆成互不关联的条目。
  - 初步分析：现有归档事项已处理会员状态刷新、购买 loading 和动态额度展示；本条应在保留这些既有行为的基础上聚焦整体 UI，不将已解决的问题重复登记为缺陷。
  - 已确认：参考图采用温暖纸张背景、手绘品牌主视觉、浅绿色权益卡、强调选中态的年/月方案与金色主操作；设置页会员区域使用同一视觉语言。
  - 实施范围：仅调整 SwiftUI 展示层和必要的私有展示组件，保留 StoreKit 产品、购买、恢复、会员刷新、额度和错误恢复逻辑。
- 影响范围：
  - iOS 设置页及其会员状态、购买入口相关界面。
  - iOS 会员购买页面，包括商品方案、权益说明、价格、购买与恢复购买操作、加载和错误状态。
  - 两个页面共用的主题、组件、文案、导航或 Sheet 展示方式，以及相关 UI 状态测试。
  - 不默认包含 StoreKit 购买逻辑、服务端会员权益或额度规则变更；若设计稿要求改变业务行为，需要另行确认范围。
- 验收标准：
  - 设置页与会员购买页面具有清晰、一致的视觉层级，会员状态、主要权益、商品信息和主要操作易于识别。
  - 从设置页进入会员购买页面、关闭或完成购买后返回的流程自然，页面状态和操作反馈不产生歧义。
  - 购买、恢复购买、商品加载、会员状态加载、失败重试、已是会员及有限或无限额度等现有状态均有完整且一致的 UI 呈现。
  - 优化后不破坏现有购买、恢复购买、会员刷新、动态额度及错误恢复行为。
  - 小屏和大屏设备、Dynamic Type、VoiceOver、Reduce Motion、浅色与深色模式下内容可读、控件可操作，且无明显截断、遮挡或布局跳动。
  - 最终 UI 符合 `docs/UI_GUIDELINES.md` 并复用项目已有主题、按钮、标题、Sheet 和导航模式。
