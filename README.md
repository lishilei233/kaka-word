# kakaword / 咔咔单词

咔咔单词是一款拍照识别物体并把英文单词标记到照片上的 iOS 学习应用。产品提供两种本地玩法：

- **自己探索**：把日常照片做成英语手账。
- **陪孩子玩**：通过每日寻宝任务累计单词并收集贴纸。

拍照后 App 会直接进入卡片详情，服务端通过 SSE 逐个返回识别到的物体，单词标签随结果实时显示。AI 同时为照片生成一句可选认真、搞笑或随机风格的英文描述。完整结果校验成功后，App 才会把压缩照片、缩略图和识别结果保存在设备本地，并在首页展示全部历史记录。历史记录不设数量上限，不上传或同步到云端；用户可以纠正中英文单词、长按调整标签与引导线位置，也可以删除单条记录或清空全部记录。

所有历史照片里的单词会自动汇总到“我的单词”，并按“学习中 / 已会”管理；每次拍照保存的完整标注照片则独立收进“发现相册”，首页只展示最近 6 张“最近发现”。用户手动标记已会后，后续识别会优先寻找其他可靠的新词；照片详情始终保留全部标签，已会词用淡色和勾号区分。“听音找词”保留真实照片听音点选玩法，每轮最多 3 个物体词，不足时按实际数量开始。照片结果页的“听音找一找”只练当前照片；首页可以开始词库练习或继续未完成的一轮。点选找到或查看答案后进入下一题，练习不会自动改变“已会”状态。结束页根据本轮表现展示不同的照片手账反馈，当前范围全部练过时展示探索完成；这不表示已经掌握。轮次进度、复习记录和照片一样只保存在当前设备。分享入口移至照片结果页的“更多”菜单。

识别完成后可直接分享带单词标注的照片卡片。应用会把当前照片卡片重新绘制为新的 JPEG，因此不会继承原照片的地点和拍摄时间元数据；应用不会自动识别或模糊人脸，分享前请自行确认画面内容。

免费体验次数实际用完后，非会员（含已到期会员）的首页会显示可关闭的会员提示卡。点击“了解会员”可查看套餐，购买成功后留在首页；从拍照受限入口购买成功后仍继续打开相机。关闭卡片后本机当天不再提醒，按设备本地自然日于次日重新判断。权益读取中或失败时不展示；已有照片和单词仍可继续学习。

设置页可独立开启“学习提醒”和“会员开通提醒”，默认均关闭，主动开启时才申请系统通知权限。学习提醒默认每天 20:00，可改时间；有可练照片时安排未来 7 天，当天完成一轮听音练习后跳过当天。会员提醒在免费次数实际用完后预约次日 12:00，本机仅提醒一次；与学习提醒同时间则顺延 10 分钟。关闭首页会员卡片不会关闭系统通知。通知点击分别进入练习或核对权益后进入会员页；没有可练内容、已经是会员或权益读取失败时回到首页。提醒基于最后一次 App 内确认的状态，无法在 App 未运行时实时检查跨设备购买，系统也可能延迟展示。

## 项目结构

- `ios/` — SwiftUI iOS App，当前阶段只做 iOS
- `server/` — Node.js + Hono API

## 本地运行后端

```bash
cd server
npm install
cp .env.example .env
npm run db:migrate
npm run dev
```

默认使用 `VISION_PROVIDER=qwen` 和 `qwen3.7-plus`。请在 `server/.env` 中填写 `QWEN_API_KEY`、`DATABASE_URL` 和随机的 `RATE_LIMIT_IP_HASH_SECRET`。如需不消耗模型额度地联调界面，可设置 `VISION_PROVIDER=mock` 和 `USAGE_LIMIT_ENABLED=false`，返回固定的 `mug / book / plant`。

## 运行 iOS

打开 `ios/PictureWord.xcodeproj`，选择 iPhone Simulator 后运行。

开发环境的服务地址集中配置在 `ios/App/AppEnvironment.swift`。模拟器可使用 `http://127.0.0.1:8787`；真机调试时改成运行后端电脑的局域网 IP，并确保手机和电脑在同一网络。
