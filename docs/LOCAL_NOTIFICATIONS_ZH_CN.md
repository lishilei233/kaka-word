# 会员与学习本地通知

## 使用方式

设置页“提醒”中独立开启学习提醒和会员开通提醒。两项默认关闭，主动开启才申请系统通知权限。拒绝权限会保留开关选择，并提供系统通知设置入口；系统权限恢复后，在返回前台时重新安排。

- 学习提醒默认 20:00，可改时间；有可用照片与学习中单词时安排包含今天在内的未来 7 个本地自然日。已过去的时刻不补发，完成一轮非空且未因内容删除而缩短的听音练习后，取消当天剩余学习提醒。
- 会员提醒在确认免费额度已用完后安排次日 12:00，同一时刻有学习提醒则改为 12:10。成功预约后持久化时间，原计划时间过去即用完本机这次提醒机会。关闭后重启、开关反复切换和会员到期不会重新获取提醒机会。
- 原计划时间尚未过去时，关闭开关或确认不再符合条件会取消预约；重新符合条件且开启时可安排新的次日提醒。
- App 确认会员有效后取消会员通知并清理通知中心对应提醒。首页卡片的当天关闭选项不会修改系统通知开关。
- 点击学习通知进入已有练习，点击会员通知重新确认权益后打开会员页；状态不符合时回到首页。正在拍照、识别或展示弹层时等待当前操作结束。App 在前台收到通知时不播放声音、不显示横幅，也不自动跳转。

## 实现与限制

通知使用系统本地预约，不包含服务器推送、设备推送令牌、APNs 或后台轮询。开关、时间、完成日期和会员预约记录仅存本机 UserDefaults；重装可能重置这些本地记录。

App 未运行时无法实时检查其他设备的购买、照片删除等变化。返回前台会重新检查；系统专注模式、通知摘要和系统权限可能延迟或阻止展示。学习通知最多预约 7 天，长期未打开后自然停止。

## 自动验证

自动测试包含通知客户端替身与日历策略，覆盖默认关闭、主动授权、拒绝及恢复、独立取消、预约去重、跨年、时区与夏令时、学习时间调整、会员一次性状态持久化、预约失败重试、整轮与部分练习、照片缺失／删除及已会词。

通知设置使用真实 UIKit 承载生成 320/430 点宽度、默认／accessibility3 字体的截图，保存在 Xcode 测试结果附件中。测试不申请真实系统通知权限，也不发送真实营销通知。

本次模拟器验证：iPhone 17 Pro / iOS 26，相关 68 项测试通过，包含通知、学习 Store 和首页会员提醒测试；Xcode 工程校验与 `git diff --check` 通过。通知端到端交互仍按下方清单执行真机验收。

## 真机验收（待执行）

- [ ] 首次安装不弹权限框；开启学习或会员提醒后仅申请一次；拒绝后保留设置且不重复申请。
- [ ] 从系统设置恢复权限并回到 App，学习提醒重新安排；两个开关相互独立。
- [ ] 将学习时间设为几分钟后，切到后台或锁屏，确认横幅、声音、无角标；前台不显示通知。
- [ ] 完成一轮练习后当天不再通知；只答一题不会取消当天通知。
- [ ] 在调试环境确认免费次数耗尽后预约会员通知；购买／恢复会员后清理待发送与已送达的会员提醒。
- [ ] 分别从冷启动、后台和其他页面点击两类通知；确认启动数据加载、会员同步、无可练内容、会员已开通和离线时的跳转。
- [ ] 在相机、识别、照片详情、单词 Sheet 和设置 Sheet 未关闭时点击通知，确认不会打断当前操作，关闭后继续处理。
- [ ] VoiceOver 可读出两个开关、说明、时间和系统设置入口；Reduce Motion 无新增动画。
