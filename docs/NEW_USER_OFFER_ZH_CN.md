# 长期新人年会员优惠：上线与验收

## 规则

- 免费体验 3 次、月会员 15 元/月；中国大陆年会员目标为首年 78 元、之后 108 元/年。
- 仅现有年会员商品配置一年期 Pay Up Front 介绍性优惠。优惠与标准会员权益、额度一致。
- 无个人截止时间、无倒计时、无服务端活动 env 开关。优惠调整由 App Store Connect 管理。
- 资格由 Apple 判定，同组只能享受一次；重装不会重置 Apple 资格。部分从未使用介绍性优惠的过期订阅用户也可能符合资格。
- App 不硬编码 78/108：金额、币种、周期来自 StoreKit。只有 Apple 确认资格且返回一年期一次支付的实际折扣才显示“新人年会员”。
- 进入付费页、返回前台重新读取商品与资格；购买前再次确认，若资格发生变化，先更新展示并让用户重新确认。Apple 购买确认页为最终扣款依据。

## App Store Connect 配置

1. 打开咔咔单词 → 订阅 → 原有订阅组 → `com.kakaword.app.membership.annual`。
2. 保留标准价格 108 元/年，在介绍性优惠中仅选择中国大陆。
3. 选择一次支付（Pay Up Front），优惠时长 1 年，价格 78 元；设定生效日期，不设置结束日期。若没有 78 元价格点，先重新确认，不能自动换价。
4. 月会员保持 15 元/月且无介绍性优惠；其他店面维持标准价格，不批量扩展此优惠。
5. 保存后重新打开优惠列表，核对地区、开始时间、无结束日期、价格、时长与支付方式。元数据传播可能需要时间。

本地 `ios/KakawordSubscriptions.storekit` 只是 Xcode 测试数据，不会写入 Apple 后台。真实 Sandbox 测试使用 StoreKit Configuration = None。

## 上线前验收

- [ ] 新 Sandbox 账号：中国大陆年会员首年 78 元，后续 108 元/年；Apple 确认页金额一致。
- [ ] 已用过同组介绍性优惠：显示标准年费，按钮不再承诺首年价。
- [ ] 无优惠店面、未配置优惠：显示 StoreKit 标准价格与币种。
- [ ] 商品加载中不承诺优惠且不能购买；失败可重试。未确认资格不显示折扣。
- [ ] 从年会员切换至月会员，按钮和续费说明同步变化。
- [ ] 购买取消不发权益；待批准不提前发权益；成功后按现行规则发放会员额度。
- [ ] 恢复购买、换设备、退出后重进、前台恢复均不会保留不再有效的优惠文案。
- [ ] 取消自动续订保留当前权益；到期恢复标准免费状态；退款、撤销按现有验证逻辑处理。
- [ ] 优惠结束后按标准年费续订，额度不重复发放。
- [ ] 小屏/大屏、大字体、VoiceOver、Reduce Motion 下完整读出首年金额与续费金额；无新增动画。

## 上线后观察

每周记录年费购买、年费占比、实际净收入、退款、取消续订和使用成本，四周后首次复盘。

现有服务端付费墙/购买统计为事件口径，不能直接当作独立用户转化率；首期无需增加活动接口或埋点字段。Apple 优惠订单、收入、退款与续订使用 App Store Connect 报表核对。新上线没有同期对照，不能仅凭首月数据断言优惠带来了增量。

78 元相对 108 元，在不计平台费用和成本差异时，需要多约 38.5% 的订单才能维持相同销售额。旧定价文档的标准价回本测算不能直接套用。
